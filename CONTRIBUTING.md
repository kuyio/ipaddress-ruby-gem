# Contributing to IPAddress

## Steps to Submit a Pull Request

* [Fork](https://help.github.com/articles/fork-a-repo) the project on GitHub.
* Make your feature addition or bug fix in a feature branch.
* Include a description of your changes in the PR.
* Push your feature branch to GitHub.
* Send a [Pull Request](https://help.github.com/articles/using-pull-requests).

## Style Guide

Please adhere to the [ruby-style-guide](https://github.com/bbatsov/ruby-style-guide) for code submissions.

## Test Coverage

All submissions of code must include test coverage which describes intent and expected behavior. The test suite uses [Minitest](https://github.com/seattlerb/minitest).

Unit tests are expected to execute quickly. We will ask you to revise any long-running tests.

## Versioning

This project uses [semantic versioning](http://semver.org/).
